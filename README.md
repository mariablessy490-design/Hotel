# Hotel Booking App
###  Project Overview
The Hotel Management App is designed to make hotel booking easy and convenient. Users can search hotels, view rooms, check prices, and book rooms through a simple and user-friendly interface.

###  Objective
The main objective is to provide an easy platform for users to find and book hotels. The app helps users save time, compare room prices, and manage their bookings easily.

###  Design Highlights
* Simple and clean user interface.
* Attractive hotel and room images.
* Blue and white colour combination.
* Easy navigation and readable text.
* Modern buttons and organized layouts.

###  Features
* Login and Sign Up: Create an account securely.
* Search Hotels: Find hotels by location.
* Room Details: View room images, facilities, and prices.
* Hotel Booking: Book rooms easily.
* Payment: Choose a payment method.
* My Bookings: View and manage reservations.
* User Profile: Manage personal details.
